# Nick Stevens — Small Business Growth site

Plain HTML/CSS/JS, no build step or dependencies needed.

## Structure
```
index.html      # the page
css/style.css   # all styling
js/main.js      # mobile nav toggle
images/         # hero photo
```

## Running it locally
Just open `index.html` in a browser, or in VS Code use the
"Live Server" extension and click "Go Live" for auto-reload while you edit.

## Notes
- Fonts (Fraunces, Work Sans) load from Google Fonts via CDN links in `index.html` — you'll need an internet connection for them to show correctly.
- The contact form posts to `formsubmit.co`, a free form-to-email service already pointed at khayostevens04@gmail.com. No backend needed.
- Pricing numbers in the Pricing section are placeholders — search `index.html` for "R450", "R1,800" etc. to edit them.
